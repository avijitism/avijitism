# Adaptive Hybrid Metaheuristic Optimization for Dynamic Task Scheduling and Resource Allocation in IoT-Enabled Mobile Edge Computing

## 📌 Project Overview

This project focuses on **dynamic task scheduling, task offloading, and computing resource allocation in Mobile Edge Computing (MEC) environments for Internet of Things (IoT) applications**.

IoT devices continuously generate computationally intensive requests. Sending all requests to a remote cloud can result in high communication latency, network congestion, and increased energy consumption. Mobile Edge Computing addresses this problem by placing computing resources closer to IoT devices.

However, MEC environments have limited computing resources and dynamically changing workloads. Therefore, an intelligent scheduling mechanism is required to decide:

1. Which IoT request should be processed?
2. Whether a request should be offloaded to an edge server.
3. Which edge server should execute the request.
4. How much computing resource should be allocated?
5. How should transmission power be allocated?
6. How can latency and energy consumption be minimized simultaneously?

This project proposes an **Adaptive Hybrid Metaheuristic Optimization framework** to solve these challenges.

## 🔬 Research Motivation

Traditional cloud computing architectures may not be suitable for latency-sensitive IoT applications because data generated by IoT devices must travel to remote cloud data centers.

MEC brings computation closer to users by deploying edge servers near IoT devices. However, MEC introduces a challenging optimization problem because:

- IoT requests arrive dynamically.
- Edge servers have limited computing capacity.
- Mobile users have different computational requirements.
- Wireless communication introduces transmission delays.
- Mobile devices have limited battery energy.
- Multiple requests compete for edge resources.
- Task offloading and resource allocation are interdependent.
- The optimization problem is computationally complex.

Metaheuristic optimization techniques can provide effective solutions to these large-scale optimization problems.

# 🧩 Problem Statement

Consider a MEC-enabled IoT environment containing:

- `M` mobile/IoT users
- `N` base stations or edge servers
- Multiple computational requests
- Limited computing capacity at each edge server
- Wireless communication channels
- Maximum transmission power constraints

Each IoT device generates a computational request characterized by:

- Required CPU workload
- Input data size
- Maximum tolerable delay
- Required computing resources

The objective is to dynamically determine the optimal scheduling and resource allocation strategy while considering:

### Primary objectives

- Minimize energy consumption
- Minimize task completion delay
- Maximize request response rate
- Maximize system welfare
- Improve edge-resource utilization

# 📚 Baseline Research

This project is inspired by the research work:

> S. Hu and G. Li, "Dynamic Request Scheduling Optimization in Mobile Edge Computing for IoT Applications," *IEEE Internet of Things Journal*, vol. 7, no. 2, pp. 1426–1437, February 2020.

The original research addresses two major optimization problems:

### 1. Uplink Power Allocation Problem (PA)

The original work uses:

**Non-Cooperative Game Model Based on Subgradient (NCGG)**

### 2. Joint Request Offloading and Computing Resource Scheduling Problem (JRORS)

The original work uses:

**Multiple-Objective Optimization NSGA-II (MO-NSGA)**

An unofficial MATLAB implementation is used as the **baseline implementation** for this project.

# 💡 Proposed Research Idea

The proposed framework introduces an **Adaptive Hybrid Metaheuristic Optimization (AHMO)** mechanism.

Instead of relying on a single optimization strategy, the proposed approach combines complementary search mechanisms.

For example:

```text
                Population Initialization

                         ▼
                Adaptive Parameter
                   Adjustment
                         │
                         ▼
                Constraint Handling
                         │
                         ▼

```

Possible algorithms that can be investigated include:

- Particle Swarm Optimization (PSO)
- Binary PSO
- Genetic Algorithm (GA)
- Grey Wolf Optimizer (GWO)
- Whale Optimization Algorithm (WOA)
- Harris Hawks Optimization (HHO)
- Ant Colony Optimization (ACO)
- Differential Evolution (DE)

The final algorithm should be selected based on a systematic literature review and experimental evidence rather than simply replacing one algorithm with another.

# 📐 Mathematical Model

Let:

- `M` = number of mobile users
- `N` = number of edge servers
- `w_i` = computational workload of task `i`
- `I_i` = input data size of task `i`
- `T_i` = maximum tolerable delay
- `f_n` = computing capacity of edge server `n`
- `p_i` = transmission power of user `i`
- `x_in` = task-offloading decision variable

where:

```text
x_in = 1  → Task i is assigned to server n
x_in = 0  → Task i is not assigned to server n
```

### Task allocation constraint

Each task can be assigned to at most one edge server:

```text
Σ x_in ≤ 1
```

### Computing-resource constraint

The total allocated computing resource cannot exceed the capacity of the edge server:

```text
Σ f_in ≤ f_n
```

### Transmission-power constraint

```text
0 ≤ p_i ≤ p_i,max
```

### Delay constraint

For every successfully completed request:

```text
T_i,total ≤ T_i,max
```

where:

```text
T_i,total =
Transmission Delay
+
Queueing Delay
+
Computation Delay
```

# ⚙️ Optimization Objective

The project can formulate the overall optimization problem as:

```text
Minimize:

F = αE + βD - γR - δW
```

where:

- `E` = energy consumption
- `D` = average task delay
- `R` = response rate
- `W` = system welfare
- `α, β, γ, δ` = weighting parameters

The optimization is subject to:

- Computing capacity constraints
- Power constraints
- Offloading constraints
- Delay constraints
- Resource availability constraints

# 📊 Performance Metrics

The following metrics should be reported.

### 1. Energy Consumption

Measures the energy required for communication and computation.

Lower is better.

### 2. Average Task Completion Delay

Measures the time required to complete IoT requests.

Lower is better.

### 3. Response Rate

```text
Response Rate =
Completed Requests / Total Requests
```

Higher is better.

### 4. System Welfare

Measures the overall benefit achieved by the MEC system.

Higher is better.

### 5. Resource Utilization

Measures how effectively MEC computing resources are utilized.

Higher utilization is desirable without causing excessive delay.

### 6. Convergence Rate

Measures how quickly the optimization algorithm reaches a good solution.

### 7. Computational Time

Measures the time required by the optimization algorithm to obtain a solution.
